ТЗ ДЛЯ AGENT
ЭТАП 1: ПЕРЕИМЕНОВАНИЕ БРЕНДА И СОЗДАНИЕ БАЗОВОГО ЛОГОТИПА ДЛЯ САЙТА

ВАЖНОЕ ПРАВИЛО
Ты работаешь только как исполнитель.
Не делаешь редизайн всего сайта.
Не меняешь структуру страниц, карточки квартир, формы бронирования, маршруты и бизнес-логику.
Не переписываешь тексты секций, кроме тех мест, где нужно заменить старый бренд на новый.
Не вносишь “улучшения от себя” за пределами задачи.

ЦЕЛЬ
Заменить бренд “Аднера” на новый бренд “ГОСТЬНИК” на всём сайте и создать простой фирменный логотип, который будет использоваться в шапке и подвале.

НОВОЕ НАЗВАНИЕ БРЕНДА
ГОСТЬНИК

ПОДЗАГОЛОВОК / ДЕСКРИПТОР
СЕТЬ ГОСТЕВЫХ КВАРТИР

ЗАДАЧА 1 — ПЕРЕИМЕНОВАНИЕ БРЕНДА
Найди все видимые упоминания бренда “Аднера” и замени их на “ГОСТЬНИК”, где это уместно по смыслу.

Обязательно проверить:
- header
- hero
- footer
- title страницы
- meta description
- og-title / seo поля, если есть
- текстовые брендовые подписи внизу сайта
- возможные alt/title/aria-label, если в них есть старое название

Важно:
- не менять смысл продающих текстов;
- менять только брендовые упоминания;
- не переписывать весь контент.

ЗАДАЧА 2 — СОЗДАТЬ ПРОСТОЙ ЛОГОТИП
Нужно создать новый логотип для бренда ГОСТЬНИК.

ТРЕБОВАНИЕ К КОНЦЕПЦИИ
Основная идея логотипа:
монограмма “Г” + образ дверного проёма / входа / гостеприимства

Логотип должен быть:
- минималистичным;
- современным;
- легко читаемым;
- аккуратным;
- не похожим на шаблонный “домик”;
- подходящим для сайта посуточной аренды;
- пригодным для маленького размера.

ФОРМАТ
Сделай логотип в виде:
- текстового блока “ГОСТЬНИК”
- компактного SVG-знака слева от названия или над ним, в зависимости от текущей композиции сайта

SVG-знак должен:
- быть простым;
- быть выполнен в одном цвете;
- хорошо смотреться на светлом фоне;
- работать в header и footer;
- быть пригодным в будущем для favicon.

ЗАДАЧА 3 — ВСТРОИТЬ ЛОГОТИП НА САЙТ
Нужно заменить текущий текстовый бренд в шапке и подвале на новый брендовый блок:
- SVG-знак
- ГОСТЬНИК
- СЕТЬ ГОСТЕВЫХ КВАРТИР

Важно:
- не ломать адаптивность;
- не делать логотип слишком крупным;
- сохранить общий стиль сайта;
- не перегружать header.

ЗАДАЧА 4 — НИЧЕГО НЕ ЛОМАТЬ
Не менять:
- карточки квартир
- тексты описаний квартир
- блок отзывов
- форму бронирования
- контакты
- мессенджеры
- структуру маршрутов
- визуальный стиль сайта целиком

ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ
- Если логотип создаётся как inline SVG или отдельный SVG-файл — использовать чистую реализацию без тяжёлых библиотек.
- Если есть компонент Header/Footer/SEO — вносить изменения аккуратно в существующую архитектуру.
- Не добавлять сторонние зависимости ради логотипа.
- Мобильная версия обязательна.

ФОРМАТ ОТЧЁТА
После выполнения покажи:
1. какие файлы изменены;
2. где именно заменён бренд;
3. как описана концепция логотипа;
4. изменялись ли SEO title и meta description;
5. подтверждение, что структура сайта и контент объектов не менялись.

СТОП-УСЛОВИЕ
После выполнения остановись.
Не делать дополнительные редизайн-улучшения.
Не предлагать новые изменения вне этой задачи.
