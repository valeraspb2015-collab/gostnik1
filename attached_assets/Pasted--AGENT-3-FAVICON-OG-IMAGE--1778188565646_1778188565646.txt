ТЗ ДЛЯ AGENT
ЭТАП 3: FAVICON И OG-IMAGE ДЛЯ БРЕНДА ГОСТЬНИК

ВАЖНОЕ ПРАВИЛО
Ты работаешь только как исполнитель.
Не делаешь редизайн сайта.
Не меняешь тексты секций, карточки квартир, отзывы, формы, маршруты, header, footer и структуру страницы.
Не меняешь логотип в интерфейсе сайта, кроме случаев, когда нужно использовать его как основу для favicon и OG-image.
Не вносишь улучшения вне этой задачи.

ЦЕЛЬ
Создать внешний брендовый слой для ГОСТЬНИК:
- favicon для вкладки браузера;
- OG-image / social preview для ссылок;
- при необходимости обновить соответствующие SEO-теги, чтобы сайт красиво выглядел при шаринге.

КОНТЕКСТ
Сайт уже переименован в ГОСТЬНИК.
На сайте уже есть логотип и фирменное написание бренда.
Нужно не менять сайт, а усилить внешний вид бренда в:
- вкладке браузера
- превью ссылки в мессенджерах
- соцсетях
- поисковой выдаче там, где используется preview

ЗАДАЧА 1 — СОЗДАТЬ FAVICON
Нужно создать favicon для ГОСТЬНИК.

КОНЦЕПЦИЯ
Использовать упрощённую версию текущего логотипа:
- знак на основе монограммы “Г” / дверного проёма
- без мелких деталей
- хорошо читается в очень маленьком размере
- не использовать длинный текст “ГОСТЬНИК” внутри favicon

ТРЕБОВАНИЯ
- favicon должен быть простым;
- контрастным;
- узнаваемым;
- хорошо смотреться на светлом и нейтральном фоне браузера;
- не терять форму в маленьком размере.

ФОРМАТЫ
Сделать корректный набор файлов/favicon-подключений в рамках существующего проекта.
Если проект уже использует favicon через index.html или head — обновить аккуратно.
Не перегружать набором лишних форматов, но сделать практично и нормально для современного браузера.

ЗАДАЧА 2 — СОЗДАТЬ OG-IMAGE
Нужно создать аккуратное social preview image для ГОСТЬНИК.

КОНЦЕПЦИЯ OG-IMAGE
Минималистичное бренд-превью:
- логотип ГОСТЬНИК
- название ГОСТЬНИК
- подпись: «Квартиры посуточно в Санкт-Петербурге и Кисловодске»
- спокойный фирменный фон
- без перегруза карточками, длинными текстами и рекламным шумом

ВАЖНО
OG-image должен выглядеть как серьёзный брендовый preview, а не как баннер из рекламы.
Минимализм лучше, чем перегруженность.

ТРЕБОВАНИЯ К OG-IMAGE
- аккуратная композиция;
- читабельность в превью Telegram / WhatsApp / соцсетей;
- соответствие бренду ГОСТЬНИК;
- размер и пропорции стандартные для social sharing;
- без фотоколлажей и визуального шума, если это не нужно.

ЗАДАЧА 3 — ОБНОВИТЬ META-ТЕГИ
Проверить и при необходимости обновить:
- og:image
- twitter:image
- favicon link tags
- при необходимости og:image:width / og:image:height
- при необходимости MIME type для иконки

ВАЖНО
Не переписывать title и description без необходимости.
Не менять canonical.
Не трогать остальной SEO-слой, если он уже корректный.

ЗАДАЧА 4 — НИЧЕГО НЕ ЛОМАТЬ
Не менять:
- тексты контента
- header
- footer
- отзывы
- hero
- карточки квартир
- формы и iframe бронирования
- структуру маршрутов
- общий стиль сайта

ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ
- использовать лёгкую реализацию;
- не добавлять тяжёлые зависимости ради генерации графики;
- если создаются изображения/ассеты — аккуратно встроить их в структуру проекта;
- убедиться, что пути корректны для production;
- мобильная версия сайта не должна пострадать.

ФОРМАТ ОТЧЁТА
После выполнения покажи:
1. какие файлы созданы;
2. какие файлы изменены;
3. как реализован favicon;
4. как выглядит концепция OG-image;
5. какие meta-теги обновлены;
6. подтверждение, что контент и структура сайта не менялись.

СТОП-УСЛОВИЕ
После выполнения остановись.
Не предлагать дополнительные улучшения.
Не начинать новый этап без отдельного задания.
